# Hype-versus-Fundamentals-in-IPO-Return-Prediction

Initial public offerings (IPOs) attract significant investor attention, yet IPO stocks tend to underperform the broader market over one to five years after listing. Loughran and Ritter (1995) documented that U.S. firms going public between 1970 and 1990 underperformed matched non-issuers by roughly 44% over five years. This long-run underperformance coexists with strong first-day returns, suggesting a gap between early excitement and actual long-run performance.
This project uses machine learning to ask whether that gap is predictable. We study 3,158 U.S. IPOs from 2009 to 2023 and predict returns at four horizons: the day of listing (Day 0), the day after listing (Day 1), two weeks, and one year. All models use the same 17 pre-IPO features at every horizon, enabling a direct comparison of how well pre-IPO information predicts performance over time. To measure performance relative to the market, we compute buy-and-hold abnormal returns (BHAR), which subtract the S&P 500 return over the same period from the IPO raw return.
Our central hypothesis is the hype versus health hypothesis: early trading behavior (hype) should predict short-run returns, while pre-IPO structural characteristics (fundamentals) should become more useful at longer horizons. We test this by comparing three models on the same observations: a hype-only model using Day-0 and Day-1 returns, a fundamentals-only model using pre-IPO features, and a full model combining both.
